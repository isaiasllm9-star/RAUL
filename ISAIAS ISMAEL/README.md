# FitLife: Sistema de Inscripción de un Gimnasio

Este repositorio contiene la solución completa al caso de estudio propuesto en la Unidad III de Lenguaje de Programación II.

## Contenido del Proyecto:
- **DOCUMENTACION.md**: Informe detallado con el modelado (Entidades, Claves, Cardinalidad y Diagramas).
- **consulta.sql**: Todos los scripts SQL necesarios (Esquema + Datos de prueba).
- **crear_db.py**: Script Python para la implementación automatizada en SQLite.
- **base_de_datos.db**: Archivo de base de datos resultante.
- **README.md**: Esta guía del proyecto.

## Cómo implementar:
Si desea regenerar la base de datos, ejecute:
```bash
python crear_db.py
```
O simplemente use el archivo SQL en su gestor de SQLite preferido.
